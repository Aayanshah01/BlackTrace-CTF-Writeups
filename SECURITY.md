# Security Policy

## Purpose

This repository contains educational cybersecurity writeups, scripts,
and notes from authorized CTFs, training labs, and security exercises.

## Supported Content

Security issues in repository scripts, documentation, or configuration
may be reported for review.

## Reporting

Do not publish sensitive vulnerability details, credentials, or private
information in a public issue.

For repository-related concerns, contact the repository maintainer
through the private contact method listed on the maintainer's profile.

## Responsible Use

- Test only systems you own or have explicit authorization to assess.
- Follow CTF and platform rules.
- Do not use repository content for unauthorized access.
- Handle discovered vulnerabilities through responsible disclosure.

## Sensitive Information

Never submit:

- Passwords or authentication tokens
- Private keys
- Personal or confidential data
- Unauthorized target information
- Restricted challenge flags or files

If sensitive information is accidentally committed, remove it from the
repository and rotate or revoke the affected secret immediately.
Deleting a file from a later commit does not erase it from Git history.

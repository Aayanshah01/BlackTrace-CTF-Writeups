# Repository Guide

## Overview

BlackTrace CTF Writeups is organized by platform and learning environment.

## Main Directories

| Directory | Purpose |
|---|---|
| `writeups/ctf/` | CTF event writeups |
| `writeups/hackthebox/` | HTB machines and challenges |
| `writeups/tryhackme/` | THM rooms and challenges |
| `writeups/other-platforms/` | Other training platforms |
| `writeups/personal-labs/` | Authorized personal lab exercises |
| `templates/` | Standardized documentation templates |
| `docs/` | Repository policies and guidance |
| `scripts/` | Writeup creation and validation automation |
| `tools/` | Supporting tool requirements |
| `.github/workflows/` | Automated repository checks |

## Challenge Folder

A typical challenge folder contains:

- `README.md` — technical writeup
- `metadata.yml` — structured challenge information
- `scripts/` — reproducible scripts, when needed
- `evidence/` — sanitized screenshots and logs
- `files/` — permitted challenge artifacts

Not every challenge requires every optional directory.

## Navigation

Start with the root `README.md`, then select the platform and challenge
category relevant to your interest.

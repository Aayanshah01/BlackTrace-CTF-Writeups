# Writeup Workflow

## 1. Select

Choose a CTF, machine, room, or authorized lab.

## 2. Prepare

Create the challenge folder using the repository helper script.
Select the appropriate template.

## 3. Investigate

Perform reconnaissance and enumeration within the permitted scope.
Record observations and hypotheses.

## 4. Solve

Document the solution path and verify important results.

## 5. Capture Evidence

Save relevant, sanitized screenshots and outputs.

## 6. Document

Complete the writeup and metadata.
Include remediation when relevant.

## 7. Validate

Run the validation scripts and review links, naming, and required files.

## 8. Review

Check accuracy, clarity, platform publication rules, and sensitive data.

## 9. Commit

Use a meaningful Git commit message.

## 10. Publish

Push the reviewed work to the repository's configured remote.

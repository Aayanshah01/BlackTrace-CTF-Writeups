# Evidence Guidelines

## Purpose

Evidence supports technical claims and helps readers verify important
steps in a challenge or lab.

## Evidence Types

- Screenshots
- Relevant command output
- HTTP requests and responses
- Logs
- Sanitized configuration excerpts
- Script output

## Naming

Use sequential, descriptive filenames:

- `step-01-recon.png`
- `step-02-enumeration.png`
- `step-03-proof-of-concept.png`

## Quality

- Capture only relevant information.
- Keep text readable.
- Reference evidence from the writeup.
- Explain what each artifact demonstrates.
- Avoid duplicate or unnecessary screenshots.

## Sanitization

Before publishing, remove or obscure:

- Personal usernames when unnecessary
- Access tokens and session cookies
- Passwords and private keys
- Personal IP addresses when sensitive
- Confidential customer or organizational data
- Any information prohibited by platform rules

Evidence must be genuine and must not be altered in a way that
misrepresents the technical result.

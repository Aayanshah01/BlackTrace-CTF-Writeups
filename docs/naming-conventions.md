# Naming Conventions

## General

Use lowercase names and hyphens.

## Platform Folders

Use recognizable platform names:

- `hackthebox`
- `tryhackme`
- `ctf`
- `personal-labs`

## Challenge Folders

Use the challenge or machine name:

- `blue`
- `baby-web`
- `linux-privesc-basics`

## Files

Preferred filenames:

- `README.md`
- `metadata.yml`
- `solve.py`
- `exploit.py`
- `requirements.txt`

## Evidence

Use sequential filenames with a short description:

- `step-01-recon.png`
- `step-02-foothold.png`

Avoid spaces, ambiguous names, and unnecessary version suffixes.
